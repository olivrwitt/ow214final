# Water quality changes in Puerto Rico after Hurricane Hugo

## Purpose/Background
This repository contains data on nutrient concentrations in several streams in the Luquillo mountain region in Puerto Rico from 1986-1994.  The purpose is to analyze changes over time in these  nutrient concentrations after the 1986.

## Contents
This data includes NO3-N, NH4-N, K, Ca, and Mg values and is stored as csv files corresponding to stream locations: Bisley1.csv (Quebrada Bisley one), bisley2.csv (Quebrada Bisley two), bisley3.csv (Quebrada Bisley three), and prm.csv (Puente Roto Mameye).  spaghetti.R create figures displaying nutrient concentration changes over time using a 9-week moving average.

## Details regarding data access
Data from: McDowell, William H., and USDA Forest Service. International Institute Of Tropical Forestry (IITF). 2024. “Chemistry of Stream Water from the Luquillo Mountains.” Environmental Data Initiative. https://doi.org/10.6073/PASTA/F31349BEBDC304F758718F4798D25458.
